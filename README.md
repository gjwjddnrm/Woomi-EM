# Woomi-EM · 우미건설 건설현장 소방안전관리 서류 작성 플랫폼

- 📝 소방안전교육 및 훈련서류 (별지 3-1·3-2)
- 🔥 화기작업 신청서·허가서 (별지 7·8)

## 사용
배포 주소(GitHub Pages)를 PC의 크롬이나 엣지로 엽니다. 처음 열면 현장명, 소방안전관리자 이름, 비밀번호를 설정합니다.

## 개인정보 보호
- 이 저장소와 사이트에는 **서식 프로그램만** 있습니다. 현장 자료(이름, 연락처, 서명, 사진)는 각 현장 PC의 브라우저 안에만 **AES-256으로 암호화**되어 저장되고, 서버나 GitHub로 전송되지 않습니다.
- 비밀번호를 잊으면 자료를 복구할 수 없습니다. 보안 설정에서 암호화 백업을 주기적으로 만들어 두세요.
- **이 저장소에 현장 자료, 백업 파일(.woomi), 출력한 PDF를 절대 올리지 마세요.**

## 수정 방법
1. `src/`의 원본 HTML을 수정합니다.
2. `python3 build/build.py`를 실행하면 `index.html`이 새로 만들어집니다.
3. 커밋하고 푸시하면 모든 현장 화면이 1~2분 안에 업데이트됩니다.
