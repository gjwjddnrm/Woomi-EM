# Woomi-EM · 우미건설 건설현장 소방안전관리 서류 작성 플랫폼

- 📝 소방안전교육 및 훈련서류 (별지 3-1·3-2)
- 🔥 화기작업 신청서·허가서 (별지 7·8)
- 🛠 안전점검 지적내역서·조치결과통보서 (별지 5·6)

## 사용
배포 주소(GitHub Pages)를 PC의 크롬이나 엣지로 엽니다. 처음 열면 현장명, 소방안전관리자 이름, 비밀번호를 설정합니다.

## 개인정보 보호
- 이 저장소와 사이트에는 **서식 프로그램만** 있습니다. 현장 자료(이름, 연락처, 서명, 사진)는 각 현장 PC의 브라우저 안에만 **AES-256으로 암호화**되어 저장되고, 서버나 GitHub로 전송되지 않습니다.
- 비밀번호를 잊으면 자료를 복구할 수 없습니다. 보안 설정에서 암호화 백업을 주기적으로 만들어 두세요.
- 현장명·소방안전관리자 이름도 암호화해서 보관합니다. 잠긴 화면에는 표시되지 않고, 잠금을 풀어야 보입니다.
- 비밀번호는 저장하지 않습니다. 자료는 무작위로 만든 자료 열쇠로 암호화하고, 그 열쇠를 비밀번호(PBKDF2-SHA256 60만 회)로 감싸 둡니다. 그래서 비밀번호를 바꿔도 자료를 다시 암호화하지 않아, 도중에 끊겨도 자료가 사라지지 않습니다.
- 새 비밀번호는 10자 이상, 영문·숫자·특수문자 중 2가지 이상이어야 합니다. 5번 틀리면 대기 시간이 걸리고, 이 대기는 화면을 거치지 않고 직접 호출해도 똑같이 적용됩니다.
- WOOMI는 **한 번에 한 창(탭)에서만** 열립니다. 두 창에서 같이 고치면 나중에 저장한 쪽이 다른 쪽 기록을 덮어쓰기 때문입니다. 다른 창에서 열려 있으면 "이 창에서 열기"를 누르세요. 먼저 열린 창은 저장을 마치고 잠깁니다.
- 화면에 넣는 글자(PDF·글자 인식·입력값)는 항상 HTML 정화를 거쳐, 숨겨진 코드가 실행되지 않습니다. 그림 주소는 그림 자료만 받고, 끼워 넣은 `<style>`도 지웁니다.
- 보안 정책(CSP)에서 `unsafe-inline`을 뺐습니다. 이 파일에 등록된 스크립트만 실행됩니다.
- 외부(CDN)에서 받는 라이브러리와 PDF·글자 인식용 작업 파일은 지문(SHA-384)을 확인한 뒤에만 실행합니다.
- "비밀번호를 잊었어요 → 전체삭제"를 하면 지우기 직전에 **암호화 보관 파일**을 먼저 내려받습니다. 예전 비밀번호가 생각나면 [보안 설정 → 백업 가져오기]로 되살릴 수 있습니다.
- **이 저장소에 현장 자료, 백업 파일(.woomi), 출력한 PDF를 절대 올리지 마세요.**

## 수정 방법
1. `src/`의 원본 HTML을 수정합니다.
2. `python3 build/build.py`를 실행하면 `index.html`이 새로 만들어집니다.
3. 커밋하고 푸시하면 모든 현장 화면이 1~2분 안에 업데이트됩니다.
